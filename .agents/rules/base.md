
# AI Agent Rules & Guidelines

## I. Core Behavioral Rules
1. **Don’t assume. Don’t hide confusion. Expose tradeoffs.**
   * Do not guess intent; ask for clarification if a prompt is ambiguous. 
   * Always present the pros and cons of different technical approaches.
2. **Write the minimum code to solve the problem. No speculative coding.**
   * Provide the simplest, most direct solution. 
   * Do not add features or logic based on "what might happen" in the future.
3. **Touch only what is necessary. Clean up only your own mess.**
   * Operate with surgical precision on the requested scope. 
   * Avoid side effects in unrelated files and leave no temporary code behind.
4. **Define success criteria. Loop until validated.**
   * Establish clear requirements before starting. 
   * Iterate and refine the output until it meets all defined goals.
