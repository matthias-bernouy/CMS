# @bernouy/binary-media

CMS-agnostic helpers for immutable byte snapshots, SHA-256 identities,
representation fingerprints, and bounded media-signature inspection.

The root entrypoint is the complete public API. The package does not own blob
storage, image transformation, authorization, or CMS-specific file semantics.

See the [workspace package map](../../../docs/architecture/packages.md). Licensed
