# Workflows

Own declarative reusable workflow manifests, typed definitions, immutable published plans, installed parameters, triggers and durable runs. Events owns subscriptions and delivery. Runtime supplies current administrator authority, installed contract resolution and authorized invocation. Repository owns catalogue publication and per-instance artifact installation through structural ports.

All management is administrator-only. The fixed event receiver also requires host delivery authority. Event payloads grant no authority. Never execute package code or bypass schema bindings. Persist intent before effects, checkpoint completions, reauthorize recovery and suspend uncertain non-idempotent commands. Encrypt retained parameters, definition/plan literals and run values through injected storage. No environment reads or production adapter selection. V1 excludes Gateway observation, external webhooks, binary steps, loops, parallel execution and arbitrary scripts.
