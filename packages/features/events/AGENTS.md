# Events

Own contract-derived installed event sources, authorized publication and durable subscriptions. Admitted contracts are the only schema authority; never accept manually registered event schemas. Platform owns neutral wire envelopes and fenced delivery, and runtime supplies verified installation ownership, selected contracts, current route checks, fingerprints and adapters.

Validate original JSON before filtering sensitive fields. Keep stable publication receipts even with zero subscribers. Freeze recipients and persist handoff before acknowledgement. Receivers commit an inbox before returning a receipt. Never expose an event-history read API or accept authority from event payloads. Keep pagination, bytes, fanout, causality and recovery bounded. No environment reads or adapter selection in this feature.
