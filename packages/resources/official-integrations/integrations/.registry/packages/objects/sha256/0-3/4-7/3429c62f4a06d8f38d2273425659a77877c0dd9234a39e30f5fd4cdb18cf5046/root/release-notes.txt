# Workspace Blocs 1.0.0

Workspace Blocs provides official layout shells for authenticated CMS tools.
The initial release installs a workspace frame, lateral navigation, and detail
layouts that compose existing Basic Blocs without introducing persistence,
network access, or provider-specific behavior.

The blocs expose editable regions and design-system settings while leaving
navigation targets, page content, and authorization to the CMS application.
Installing the package is deterministic and may be repeated to restore its
versioned official sources.
